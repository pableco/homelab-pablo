Política de privacidad

homelab-pablo es una herramienta de uso personal. Solo accede a cuentas de Google de su propietario, Pablo Grillo, que la autoriza expresamente.

  • Qué datos usa: los mensajes de Gmail, con el permiso de solo lectura (gmail.readonly). No puede enviar, modificar ni borrar correos.
  • Para qué: guardar una copia de seguridad del correo en un servidor doméstico del propietario.
  • Dónde se guardan: únicamente en ese servidor. No se envían a terceros, no se venden y no se usan para publicidad.
  • Cómo revocar el acceso: en myaccount.google.com/permissions.

El uso de los datos recibidos de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
